Una variable es una caja con nombre. let puntos = 10; guarda un 10 en la caja puntos.
Por defecto es inmutable: la caja está cerrada con candado. puntos = 20; no compila.
Con mut quitas el candado: let mut puntos = 10; permite cambiar el valor. Ahora puntos = 20; funciona.
Shadowing: let x = x + 1; crea una caja nueva con el mismo nombre que tapa a la anterior.
Una variable es un nombre que le das a un valor para poder usarlo después. En Rust se declaran con let y tienen una particularidad que sorprende al principio: por defecto no se pueden modificar.
No es un capricho. Si un valor no cambia, es más fácil razonar sobre el código y el compilador puede garantizar que nadie lo modifica a tus espaldas. Cuando necesites que cambie, lo dirás de forma explícita.
No hace falta indicar el tipo: Rust lo infiere a partir del valor. Si quieres, puedes escribirlo tú después del nombre, separado por dos puntos:

Nombres: Las variables se escriben en snake_case: minúsculas y palabras separadas por guiones bajos, como puntos_totales. Si usas camelCase, el compilador te avisará.

Añade mut delante del nombre y la variable podrá cambiar de valor:
puntos += 5 es la forma corta de escribir puntos = puntos + 5. También existen -=, *=, /= y %=.
Ten en cuenta dos cosas:
mut permite cambiar el valor, pero no el tipo: si la variable guarda un número, siempre guardará un número.
Si marcas una variable como mut y nunca la modificas, el compilador te avisa con un warning: variable does not need to be mutable. Usa mut solo cuando lo necesites.
Para valores fijos que no cambian nunca, como un límite o un dato de configuración, usa const:
Las constantes se diferencian de las variables en varias cosas:
Siempre son inmutables: no admiten mut.
El tipo es obligatorio: no se infiere.
Se escriben en MAYÚSCULAS_CON_GUIONES_BAJOS.
Pueden declararse fuera de cualquier función, a nivel global.
Su valor tiene que poder calcularse al compilar, como 60 * 60.
Legibilidad: Puedes usar _ para separar las cifras de un número largo: 1_000_000 es lo mismo que 1000000, pero se lee mucho mejor.
