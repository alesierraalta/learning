## Specs

- S1 (engine): the video system is a versioned engine in this repository (`tools/video/`), not a per-part script on one host. A new part needs a spec file only; no engine code change. ("We have to build our own video creation system.")
- S2 (engine): a scene is animated, not revealed. The engine renders every frame as a pure function of time (`frame(t)`), so a render is deterministic and re-runnable; motion comes from interpolation (draw-on strokes, travelling arrows, staggered build-up, crossfade of changed elements), never from a pre-baked slideshow.
- S3 (engine): the drawing vocabulary is the notes' own `integrations/pi/kit/scene.js` (boxes, arrows, grids, sheets, nodes, gears, labels). No second drawing language, no characters or avatars: the figure is the example itself. ("like not characters at all")
- S4 (engine): one source of truth. A video scene either plays a real `<lk-walkthrough>` deck read from the part's note, or is composed from the same primitives in the spec; the video never draws something the note does not draw.
- S5 (engine): visuals are anchored to speech. Every state change names the word it lands on (or a fraction of the beat), and is resolved against the TTS word boundaries, so the drawing changes when the voice says it. A beat with no anchors spreads its states evenly and that is recorded in the report.
- S6 (content): one idea per beat, and the figure carries it: a frame sampled at the beat's midpoint must be understandable with the sound off. No text walls; a table may appear only when an arrow points into it.
- S7 (delivery): output keeps the existing contract — 1920x1080, 30 fps, H.264 CRF 20, AAC 192k, SRT from word boundaries, delivered to `~/Learnings/<topic>/explicaciones/adjuntos/` with the part's exact name, and the page's 🎬 becomes a player.
- S8 (proof): Part 3 of `fundamentos-aprendizaje-por-refuerzo` is rebuilt with the engine as the before/after: same narration, new visual track. The old MP4 is kept as the "before" for comparison.
