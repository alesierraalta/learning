TCP y capas

Capas que cooperan

Una comunicación de red se divide en capas para que cada una resuelva una parte del problema. La aplicación genera datos; la capa de transporte organiza su entrega entre procesos.

TCP establece una conexión y divide los datos en segmentos numerados. El receptor confirma lo que ha recibido y el emisor puede volver a enviar un segmento perdido.

La capa de red utiliza IP para llevar paquetes entre redes. Cada router consulta la dirección de destino y decide por dónde continuar el viaje.

En cada enlace, una trama transporta el paquete hasta el siguiente equipo. Esa trama cambia de un tramo a otro, aunque el destino IP siga siendo el mismo.

Al llegar, las capas trabajan en sentido inverso: cada una interpreta su información y entrega el contenido a la capa superior.
