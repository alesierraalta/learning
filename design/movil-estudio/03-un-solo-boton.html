TCP y las capas de red

Al enviar un mensaje, cada capa de la red aporta una función. La aplicación entrega datos a TCP, que los divide en segmentos y mantiene el orden de entrega.

TCP identifica los segmentos y espera confirmaciones. Si falta información, puede retransmitirla; así la aplicación recibe un flujo fiable de bytes.

IP dirige los paquetes entre redes mediante direcciones. En cada salto, la capa de enlace transporta el paquete hasta el siguiente dispositivo.

Estas responsabilidades son complementarias: IP encuentra una ruta posible y TCP comprueba que el flujo llegue completo.
